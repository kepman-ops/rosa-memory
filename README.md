# Сайт памяти Розы

Статический сайт для GitHub Pages с семейной историей Розы, хронологией и местом для фотографий.

## Страницы

- `index.html` — главная страница сайта памяти.
- `story.html` — оформленная семейная история Розы.
- `timeline.html` — краткая хронология событий.
- `gallery.html` — галерея с заглушками для будущих фотографий.
- `style.css` — общие стили сайта.
- `images/` — иллюстрации и будущие семейные фотографии.

## Как опубликовать на GitHub Pages

1. Откройте репозиторий на GitHub.
2. Перейдите в `Settings` → `Pages`.
3. В блоке `Build and deployment` выберите `Deploy from a branch`.
4. Выберите ветку `main` и папку `/root`.
5. Нажмите `Save`.

После публикации сайт будет доступен по адресу вида:

```text
https://<github-login>.github.io/rosa-memory/
```

## Как добавить настоящие фотографии

1. Положите файлы в папку `images/`, например `rosa-01.jpg`, `family-01.jpg`.
2. Откройте `gallery.html`.
3. Замените пути к заглушкам на пути к новым фотографиям.
4. Обновите подписи и `alt`-тексты.

Не публикуйте документы, адреса, телефоны, медицинские сведения и фотографии живых людей без согласия.
